# Decision Programming — IR-B&B

Research repository for the **Information-Relaxation Branch-and-Bound (IR-B&B)** study of the **Extended Oil Wildcatter Problem** within Decision Programming.

## Repository structure

```text
paper/
  main.tex       # Research manuscript (LaTeX)
  figures/       # Figures for the manuscript
src/             # Algorithm implementation (to be added)
experiments/     # Experiment scripts and results (to be added)
```

The manuscript is currently a working draft. The source code and experimental materials will be organized in their corresponding folders as they are added.

## Paper

The current manuscript is in [`paper/main.tex`](paper/main.tex). From the `paper/` directory, it can be compiled with `latexmk -pdf main.tex` in an environment with the required LaTeX packages.
